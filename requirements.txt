# Typical usage:
#   python -m pip install --upgrade pip setuptools wheel
#   python -m pip install -r requirements.txt
#   python -m pip install -c constraints.txt -e .
#   python -m pip install -c constraints.txt -e ".[dev]"
#
# Notes:
# - This file intentionally tracks the supported core + dev baseline that repository checks validate.
# - Optional ml/data/cloud/audio stacks remain declared in pyproject extras and are installed separately.
# - constraints.txt carries shared anchor pins used by editable installs and extras.
# - Platform-specific markers remain inline where needed.
# - Keep the pip pin in constraints.txt only. Exact self-pins break pip-compile-based
#   dependency submission when the runner is executing under a different pip version.
# - pavucontrol remains a Debian/system package, not a pip dependency when the optional
#   audio stack is installed.
# - Patched wheel overlays (for example Redis vector-store compatibility) are optional and documented in docs/development/patched-wheels.md.
