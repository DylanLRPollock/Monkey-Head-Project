# Contributing to the Monkey Head Project

Thank you for your interest in improving the project! We welcome issues and pull requests from the community.

## Quick Start

- Fork the repository on GitHub and create a feature branch.
- Follow the coding standards enforced in CI (`black` and `flake8`).
- Write or update tests in `tests/` and ensure `pytest` passes.
- Submit a pull request targeting the `master` branch with a clear description.

For detailed guidelines including environment setup, commit message conventions, and community channels, see [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).
