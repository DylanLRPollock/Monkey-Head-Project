## 1. Introduction

Linux for PlayStation 2 (PS2 Linux) represents a unique chapter in computing history. Sony officially released a Linux development kit in 2002, allowing the PlayStation 2 console to function as a personal computer. This was followed by extensive community-driven homebrew development that expanded Linux compatibility to a wider range of PS2 models.

### 1.1 Document Scope

This guide covers:
- **Path 1:** The official Sony Linux Kit (for "fat" PS2 models)
- **Path 2:** Homebrew Linux installation (for all compatible models)
- **Performance insights** and practical limitations
- **Troubleshooting** common issues
- **Community resources** and current status

## 2. PlayStation 2 Hardware Overview

### 2.1 Core Specifications

| Component | Specification |
|-----------|---------------|
| **CPU** | "Emotion Engine" — 128-bit MIPS R5900, 294.912 MHz (original) / 299 MHz (later models) |
| **Main RAM** | 32 MB RDRAM |
| **Video RAM** | 4 MB eDRAM (embedded in Graphics Synthesizer) |
| **GPU** | "Graphics Synthesizer" — 147.4 MHz |
| **Storage Interface** | IDE (via Network Adaptor for fat models) or USB 1.1 |
| **Network** | 100Base-T Ethernet (via Network Adaptor) |
| **USB** | USB 1.1 (two ports) |

**Verification:** The PS2 uses a single-core "Emotion Engine" CPU, clocked at 294.912 MHz in original fat models, and 299 MHz in newer slim models. It has 32 MB RDRAM and 4 MB eDRAM.

### 2.2 Model Compatibility Matrix

| PS2 Model Series | Official Kit | Homebrew HDD Support | Kernelloader Status | Notes |
|------------------|-------------|---------------------|---------------------|-------|
| **SCPH-10xxx (JP)** | Yes (JP Kit) | External PCMCIA IDE | Should work (V1: sound not auto-detected) | Requires JP Linux Kit with PCMCIA HDD unit |
| **SCPH-3xxxx (Fat)** | Yes (US/EU Kits) | Internal IDE (via Network Adaptor) | Working (V3, V4, V6: sound auto-detected) | Requires Network Adaptor for internal HDD; ideal for most installations |
| **SCPH-5xxxx (Fat)** | Yes (US/EU Kits) | Internal IDE (via Network Adaptor) | Working (V9-V11: sound not auto-detected) | Generally good compatibility |
| **SCPH-70xxx (Slim)** | No | USB Only | V12/V13: USB stable with kernel patch | Not recommended; no standard internal HDD support |
| **SCPH-75xxx/77xxx (Slim)** | No | USB Only | V14+: USB unstable with Linux 2.4; stable with 2.6 | Kloader 2.6+ recommended |
| **SCPH-79xxx (Slim)** | No | USB Only | Similar to 75xxx/77xxx | USB stability is a concern |
| **SCPH-9xxxx (Slim)** | No | USB Only (if at all) | Less compatible; Kloader 2.6+ recommended | May have further restrictions |

**Critical Note:** Free MCBoot is incompatible with SCPH-9000x models (BIOS 2.30 and up). FreeDVDBoot works on all Slim consoles but not all Fat consoles.

## 3. Path 1: Official Sony Linux Kit

### 3.1 Kit Contents

The **"Linux (for PlayStation 2)" Release 1.0** kit included:

| Component | Specification |
|-----------|---------------|
| **Hard Disk Drive** | 40 GB IDE (Expansion Bay Type) |
| **Network Adaptor** | 100Base-T Ethernet |
| **Linux Distribution** | Two DVDs (Runtime Environment + Software Packages) |
| **Kernel** | Linux 2.2.1 with USB device support |
| **Development Tools** | GCC 2.95.2, glibc 2.2.2, VU assemblers |
| **Graphics** | XFree86 3.3.6 with PS2 GS support |
| **Monitor Adaptor** | VGA adapter with audio connectors |
| **Input Devices** | USB keyboard and mouse (PlayStation colors) |

**Additional Requirements:**
- PlayStation 2 console (specific compatible models)
- 8 MB Memory Card (must be formatted, erasing all data)
- VESA monitor supporting XGA (1024×768) with **sync-on-green** capability

### 3.2 Release Information

| Region | Release Date | Price |
|--------|-------------|-------|
| **Japan (Beta)** | June 2001 | 25,000 yen (1,000 units) |
| **North America** | May 2002 | $199 USD |
| **Europe** | May 2002 | £155 GBP |

**Verification:** The kit was designed as a hobbyist development environment. The official kit is now a collector's item and commands high prices.

### 3.3 Installation Process (Official Kit)

1. **Hardware Setup:** Install Network Adaptor, connect 40GB HDD, connect USB keyboard/mouse, connect VGA monitor
2. **Insert Memory Card:** 8 MB card into slot 1 (will be formatted)
3. **Boot from Disk One:** Insert Runtime Environment DVD, select "Install"
4. **Disk Swapping:** Follow prompts to swap Disk One and Disk Two
5. **Partitioning:** Use Disk Druid to create swap partition (1 GB recommended) and root partition (ext2)
6. **System Configuration:** Set hostname, network, time zone, root password, user account
7. **First Boot:** After installation, reset PS2, boot from HDD, log in, type `startx`

### 3.4 Pros and Cons (Official Method)

| Pros | Cons |
|------|------|
| All-in-one, officially sanctioned solution | Kit now extremely rare and expensive |
| Relatively straightforward installation | Limited to specific "fat" PS2 models |
| Pre-configured for PS2 hardware | Very old distribution (Kernel 2.2.1, late 1990s tech) |
| Includes development tools | DVD-ROM drive cannot read data discs (piracy restriction) |

**Key Limitation:** The DVD-ROM drive could not be used for general data access (reading data DVDs, installing software from CD/DVD). It could only read PS1 and PS2 game discs for identification purposes.

## 4. Path 2: Homebrew Linux

### 4.1 Exploits and Bootloaders

| Tool | Type | Description |
|------|------|-------------|
| **Free MCBoot (FMCB)** | Softmod | Most popular memory card exploit; incompatible with SCPH-9000x |
| **FreeDVDBoot** | DVD exploit | Works on all Slim consoles; not all Fat consoles |
| **Kernelloader** | Bootloader | Open-source bootloader for PS2 Linux |
| **uLaunchELF** | File manager | Browse files, execute .ELF files |

**Verification:** Kernelloader is a free bootloader for PS2 Linux and other PlayStation 2 operating systems. Loading can be done by "Action Replay Media Player," "memory card exploit," "FMCB," or any other homebrew loading method.

### 4.2 Software Components

| Component | Description | Example Files |
|-----------|-------------|---------------|
| **Linux Distribution** | Debian-based for PS2 | BlackRhino Linux 1.0, Debian 5 "Lenny" |
| **Kernel** | MIPS-compiled for PS2 | `vmlinux`, `vmlinux.devfs`, `vmlinux_v11.gz` |
| **Initrd** | Initial RAM disk | `initrd.gz`, `initrd.usb2.gz` |
| **Bootloader** | Kernelloader executable | `kloader3.0.elf` |

### 4.3 Installation Process (Homebrew — Internal HDD)

1. **Install Free MCBoot** onto memory card
2. **Copy files** to memory card folder (`kloader/`): `kloader3.0.elf`, `vmlinux.devfs`, `initrd.gz`
3. **Boot Kernelloader** via uLaunchELF
4. **Select kernel** (`vmlinux.devfs`) and initrd (`initrd.gz`)
5. **Partition HDD** using `fdisk`:
   - Create swap partition (+128M)
   - Create root partition (rest of drive)
   - Set types: 82 (swap) and 83 (Linux)
6. **Format partitions**:
   - `mkswap /dev/hda1`
   - `mke2fs /dev/hda2`
7. **Mount and extract** BlackRhino base image from USB
8. **Configure fstab** with correct partition paths
9. **Boot full system** with kernel parameters: `root=/dev/hda2 ro crtmode=pal` (or `ntsc`)
10. **Login** and run `startx`

### 4.4 Installation Process (Homebrew — USB for Slim Models)

For slim PS2 models without internal HDD support:

1. **Prepare USB drive** on separate Linux PC:
   - Partition: ext2 root + swap
   - Copy Debian base files, `vmlinux_v11.gz`, `initrd.usb2.gz`
2. **Prepare memory card** with FMCB and Kernelloader files
3. **Boot Kernelloader** and configure:
   - Select kernel: `vmlinux_v11.gz`
   - Select initrd: `initrd.usb2.gz`
   - Kernel parameter: `newroot=/dev/sda1`
4. **Boot into Debian** from USB

**Note:** USB 1.1 is significantly slower than internal IDE, and stability can be a concern on later slim models.

## 5. Performance and Limitations

### 5.1 Performance Characteristics

| Component | Specification | Linux Implication |
|-----------|---------------|-------------------|
| **CPU** | ~295–299 MHz MIPS R5900 | Sufficient for CLI; struggles with heavy GUI |
| **Main RAM** | 32 MB RDRAM | **Severe bottleneck**; limits multitasking and application size |
| **Video RAM** | 4 MB eDRAM | Adequate for 2D desktop; not for 3D |
| **Storage** | IDE HDD (fat) or USB 1.1 (slim) | IDE offers better performance than USB 1.1 |
| **Network** | 100Base-T Ethernet | Adequate for basic networking |

**Comparison:** The PS2's CPU performance is roughly comparable to a high-end desktop PC from around 1997, or approximately 60% of a Raspberry Pi Model 1.

### 5.2 Known Limitations

| Limitation | Description |
|------------|-------------|
| **DVD Drive Access** | Restricted to PS1/PS2 game discs only (piracy prevention) |
| **Sound Support** | Inconsistent across models; V9-V11 and slim models lack auto-detection |
| **USB Stability** | USB 1.1 is slow; stability issues on some slim models |
| **Limited RAM** | 32 MB severely restricts application size and multitasking |
| **No Wi-Fi** | Requires wired Ethernet via Network Adaptor |
| **Graphics Acceleration** | 2D only; 3D acceleration not comparable to native games |

### 5.3 Software Capabilities

Despite constraints, usable applications include:

| Category | Applications |
|----------|--------------|
| **Web Browsers** | Dillo (lightweight), older Mozilla Suite |
| **IRC Clients** | XChat |
| **Instant Messaging** | Pidgin (formerly Gaim) |
| **Text Editors** | vi, nano, pico |
| **Development** | GCC, VU assemblers, XFree86 |

## 6. Troubleshooting Common Issues

| Issue | Likely Cause | Solution |
|-------|-------------|----------|
| **Kernelloader fails to load** | FMCB not installed correctly | Verify FMCB installation; check memory card |
| **Kernel panic during boot** | Incorrect kernel parameters | Check `root=` parameter; verify partition paths |
| **HDD not detected** | Network Adaptor not connected | Ensure Network Adaptor is securely connected |
| **Network not working** | Driver issues or cable problem | Check Ethernet cable; try "improved SMAP beta drivers" |
| **USB devices not working** | USB stability issues | Try different USB ports; enable USB patch in Kernelloader |
| **No display/garbled image** | Incorrect crtmode | Set `crtmode=pal` or `crtmode=ntsc` appropriately |
| **Applications crashing** | Insufficient RAM | Reduce running processes; enable swap |
| **Slow performance** | RAM/swap thrashing | Reduce workload; verify swap is active |

## 8. Implications for Monkey-Head-Project

The PS2 Linux project serves as a **historical case study** in repurposing consumer hardware for general-purpose computing.

| Aspect | Relevance |
|--------|-----------|
| **Hardware Repurposing** | Demonstrates creative reuse of gaming hardware |
| **Community-Driven Development** | Model for homebrew and retrocomputing efforts |
| **Hardware Constraints** | Illustrates how RAM limitations impact system design |
| **Preservation** | Documents an era when manufacturers embraced open platforms |
| **Ethos Alignment** | "Breathing new life into old tech" — PS2 Linux exemplifies this |

**LabTech Recommendation:** The PS2 Linux project is retained as a historical reference for understanding hardware repurposing and community-driven development. For practical retrocomputing, modern alternatives (Raspberry Pi, emulation) offer superior performance and support.
