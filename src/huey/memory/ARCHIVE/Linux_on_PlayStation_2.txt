Network Adapter (Ethernet): For "fat" PS2 models (SCPH-3xxxx to SCPH-5xxxx series), the official Sony

compatible, and drivers were available for modem support under PS2 Linux.7
The PS2's peripheral ecosystem, particularly the Network Adapter, played a pivotal role. Its dual
function?providing both network connectivity and the crucial IDE interface for an internal HDD?made it an
enabler for serious Linux use on the "fat" PS2 models.7 However, this design also became a point of
fragmentation. When Sony transitioned to the "slim" PS2 designs, the Expansion Bay and, consequently, the
integrated IDE support via the Network Adapter were largely omitted.7 This hardware alteration significantly
complicated Linux installation on slim models, often pushing users towards less performant USB-based
storage solutions or intricate hardware modifications.7
PS2 Memory Card (8MB Minimum): An 8MB PlayStation 2 Memory Card is required for the official Linux Kit
installation process.7 For homebrew methods, a memory card is highly recommended, and often essential,
for storing bootloader software (like Kernelloader.elf launched via Free MCBoot) and system configuration
files.7 Some homebrew setups, including the kernel, initial RAM disk, and bootloader, can occupy 7MB to

USB Keyboard and Mouse: A standard USB keyboard and mouse are essential for interacting with the Linux
command line, bootloader menus, and any graphical environment.2 The official Sony Linux Kit included both
peripherals.

CPU: The PlayStation 2 is powered by the "Emotion Engine," a custom MIPS R5900-based CPU clocked at
approximately 300 MHz (294.912 MHz, or 299 MHz in some later versions).5 For general-purpose computing
under Linux, its performance has been anecdotally compared to that of a high-end desktop PC from around

RAM: The most significant performance bottleneck for Linux on the PS2 is its main memory: just 32MB of
RDRAM (Rambus DRAM).5 This limited amount of RAM severely restricts multitasking capabilities and the
types of applications that can run effectively. Console hardware of that era often featured relatively low RAM
amounts compared to contemporary PCs to keep costs down.16
Video RAM: The PS2 has 4MB of embedded DRAM (eDRAM) for video memory, integrated within the
"Graphics Synthesizer" (GS).5 This is sufficient for basic 2D desktop acceleration under XFree86 but is not
intended for demanding 3D graphics rendering within a Linux environment.
