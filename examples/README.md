This directory contains small standalone examples demonstrating features of the
Monkey Head Project and the bundled PyGPT toolkit. Each script can be executed
directly and is intentionally lightweight so it can run without external
dependencies beyond those already included in the project.

Available examples include:

- ``example_audio_input.py`` – read a WAV file and print its duration.
- ``example_audio_output.py`` – generate a sine wave and save it to a file.
- ``example_data_loader.py`` – load rows from a CSV file.
- ``example_llm.py`` – use ``AIProcessor`` to process text input.
- ``example_plugin.py`` – minimal plugin skeleton for PyGPT.
- ``example_tool.py`` – custom tool integrated with the PyGPT GUI.
- ``example_vector_store.py`` – in-memory vector store with cosine search.
- ``example_web_search.py`` – fetch the first DuckDuckGo search result.

Run any script with ``--help`` for usage details.
